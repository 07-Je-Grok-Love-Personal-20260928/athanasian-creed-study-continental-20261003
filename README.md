# 欧陆改革宗 · 亚他那修信经研读

静态页面，讲解拉丁信经 *Quicunque vult*（《亚他那修信经》）。**非亚他那修亲笔**。成文约在五世纪末至六世纪初的拉丁西方（多指向高卢南部），后来与阿尔勒的凯撒留圈子的使用相连；在西方被领受并用于礼仪，不是大公会议颁布的信经。

页脚版本 v20261003。正文为中文教学讲解；信经条款是教学译文，不是现代版权译本的全文转载。三项联合信条只标条款号。

## 页面里有什么

- 一句记忆：一神三位，不混不分；基督一位，二性不混不离
- 整本圣经故事线（卡片，无交叉连线）：创造、堕落、应许、道成肉身、十字架、复活、圣灵、再来
- 高卢 / 罗马 / 君士坦丁堡示意地图
- 时间线：圣经节点、325、381、五世纪末至六世纪初、中世纪西方使用、1561、1563
- 三信经对照、位格与本性、四种偏差各一行
- 逐段：前因、背景、写了什么、经文、圣约、信条编号、难点、应用、记忆句
- 短记忆路径（不是五十二周）
